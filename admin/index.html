Configuração inicial

Feita uma única vez. O painel guarda a chave do GitHub trancada com a senha — depois disso, basta a senha para entrar.

Como criar a chave de acesso no GitHub
  1. Abra github.com/settings/personal-access-tokens/new (logado na conta dona do site).
  2. Token name: Painel site Tey. Expiration: a maior opção disponível.
  3. Repository access: “Only select repositories” → escolha o repositório do site.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Clique em Generate token, copie o código (começa com github_pat_) e cole abaixo.
